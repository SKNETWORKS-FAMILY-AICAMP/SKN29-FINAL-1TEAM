## 1. 개요

### 1.1 목적

이 문서는 법인카드 사용 내역이 정산 시스템에 들어왔을 때 Rule 콘솔이 조건에 따라 승인·보완요청·반려 방향을 1차로 분류하여 재무회계팀의 검토 업무를 자동화할 수 있도록, 업무추진비·회식·출장 3개 카테고리에 대해 사내 규정 조항을 근거로 한 RULE을 정의한다. 각 RULE은 Rule 콘솔에서 "조건(condition) → 액션(action)" 형태로 등록되며, 출처 조항을 태깅해 규정 개정 시 영향받는 RULE을 추적할 수 있도록 한다.

### 1.2 처리 프로세스

모든 RULE은 다음 흐름을 거쳐 실제 서비스에 반영된다.

- **RULE 초안 등록** — 담당자가 규정 조항을 근거로 RULE 초안을 Rule 콘솔에 등록("Rule 초안 대기" 상태).
- **시뮬레이션** — 과거 정산 이력 데이터로 매칭 건수·오탐율(False Positive)·예상 검토 감소량을 검증하고, 기존 Active Rule과 조건이 겹치는지 확인한다.
- **승인 및 Active 전환** — 팀장급 이상 승인권자가 시뮬레이션 결과를 검토해 "승인(ACTIVE 전환)"하면 신규 버전으로 반영되고, 이전 버전은 롤백 가능한 상태로 보존된다.
- **운영** — Active Rule이 실제 정산 건에 적용되어 검토 워크스페이스에서 승인/보완요청/반려 추천 의견과 근거(RAG 인용 조항)를 함께 제시한다.

### 1.3 최종 처리 상태와 인적 책임

RULE 엔진이 산출하는 액션·심각도·권장 처리는 검토 워크스페이스에서 담당자가 아래 3개 상태 중 하나로 최종 확정하기 위한 참고 자료이며, 심각도가 CRITICAL인 경우에도 시스템이 자동으로 확정 처리하지 않는다. 손금산입 여부 및 정산 승인에 대한 최종 판단과 책임은 관리자 및 재무회계팀에 있다(법인카드 사용 규정 제16조 인적 책임의 원칙).

- **승인(APPROVE)** — 조건 충족, 증빙·기록 이상 없음.
- **보완요청(RETURN)** — 증빙·기록 보완 또는 소명 후 재검토.
- **반려(REJECT)** — 정책 위반·손금불산입 위험이 확정되어 정산을 거부.

## 3. 심각도 및 권장 처리 매핑 기준

모든 RULE의 액션에는 심각도(severity)가 함께 부여되며, 심각도별 기본 처리 원칙은 다음과 같다. 개별 RULE은 이 기준을 기본값으로 하되, 규정상 특성에 따라 권장 처리를 별도로 지정할 수 있다.

| 심각도 | 정의 | 권장 처리 원칙 |
|---|---|---|
| **CRITICAL** | 정책상 명백히 금지된 행위(유흥업소·사행성 업종 결제, 상품권 현금구매, 2차 유흥업소 결제 등) | 자동 반려 후보 — 검토 워크스페이스 최상단에 노출, 관리자가 최종 반려를 확정한다(자동 확정 아님). |
| **HIGH** | 손금불산입·청탁금지법 위반 등 세무·법률 리스크가 큰 사안 | 반려 권고 또는 법무·상위 승인자 에스컬레이션 — 사람 확인 후 반려 또는 소명 수리. |
| **MEDIUM** | 사전승인 누락, 한도 초과, 참석·목적 기록 불충분 등 절차 위반 | 보완요청 또는 지정 승인자 승인 확인 전까지 보류. |
| **LOW** | 사전승인 대상 알림, 참고성 확인이 필요한 경미한 사안 | 승인 대기 확인 — 지정 승인자 승인 이력만 확인되면 통과. |
| **INFO** | 통계·리스크 등급 산정을 위한 모니터링용 참고 플래그 | 개별 건 처리에는 영향 없음 — 사용자 리스크 등급·정기 점검 리포트에만 반영. |

## 4. 업무추진비 RULE (R-1xx)

「기업업무추진비 사용 규정」(TIGER-REG-2026-005)을 근거로 도출한 13개 RULE이다. 회식 중 외부인이 참석해 재분류되는 건(R-204)에도 이 RULE셋 전체가 함께 적용된다.

### 개요표

| ID | 제목 | 조건 요약 | 심각도 | 권장 처리 |
|---|---|---|---|---|
| R-101 | 증빙 미비 손금불산입 위험 | 업무추진비 3만원 초과 & 적격증빙 미수취(경조사 제외) | **HIGH** | 반려 권고 |
| R-102 | 사전승인 미확인 — 30만~100만원 | 업무추진비 30만원 초과~100만원 이하, 부서장 사전승인 기록 없음 | **MEDIUM** | 지정 승인자 승인 확인 전까지 보류, 미확인 시 보완요청 |
| R-103 | 사전승인 미확인 — 100만~300만원 | 업무추진비 100만원 초과~300만원 이하, 부서장 이상 승인 없음 | **MEDIUM** | 지정 승인자 승인 확인 전까지 보류, 미확인 시 보완요청 |
| R-104 | 사전승인 미확인 — 300만원 초과 | 업무추진비 300만원 초과, 본부장 이상 승인 없음 | **HIGH** | 고액 구간이므로 승인 미확인 시 반려 권고로 상향 처리 |

| R-108 | 기록 사항 누락·불충분 | 거래처·참석자 정보 또는 지출목적 기재 누락/포괄적 기재 | **MEDIUM** | 보완요청 |
| R-109 | 금지업종·현금성 사용 | 유흥업소·사행성업종 사용, 상품권 현금 구매 | **CRITICAL** | 자동 반려 후보 |
| R-110 | 봉사료 과다 포함 | 결제금액 중 봉사료 10% 이상 포함 | **MEDIUM** | 소명자료 제출 요청 |
| R-111 | 경조사 화환·조의금 증빙 미비 | 경조사성 지출 20만원 초과, 소명자료 없음 → 전액 손금불산입 | **HIGH** | 반려 권고 |
| R-112 | 반복·고액 접대 모니터링 | 동일 거래처 3개월 내 3회 이상 또는 1회 100만원 초과 | **MEDIUM** | 업무 관련성·적정성 별도 확인 |
| R-113 | 기록 기한 초과 (3영업일) | 지출일로부터 3영업일 초과 후 정산 시스템 기재 | **LOW** | 보완요청 |

### 상세 명세

#### R-101 · 증빙 미비 손금불산입 위험

- **조건(자연어):** 기업업무추진비 지출로 건당 금액이 3만원을 초과하는데 적격증명서류(신용카드매출전표 등)를 수취하지 못한 경우. 경조사성 화환·조의금 등은 R-111을 별도 적용한다.
- **조건(룰 엔진 표현식):** `category == "기업업무추진비" AND item_type != "경조사" AND amount > 30000 AND has_valid_receipt == false`
- **액션 · 심각도:** `flag = "NON_DEDUCTIBLE_RISK"` · severity = **HIGH**
- **권장 처리 · 확인/승인자:** 반려 권고 — 소명자료 없는 한 전액 손금불산입 대상이므로 반려 · 재무회계팀
- **출처 조항:** *기업업무추진비 사용 규정 제11조①, 법인카드 사용 규정 제11조②*

#### R-102 · 사전승인 미확인 — 30만~100만원

- **조건(자연어):** 기업업무추진비 지출 금액이 30만원 초과 100만원 이하인데 부서장(또는 사전 지정 대리인)의 사전승인 기록이 확인되지 않는 경우.
- **조건(룰 엔진 표현식):** `category == "기업업무추진비" AND 300000 < amount <= 1000000 AND pre_approval_level < "부서장"`
- **액션 · 심각도:** `flag = "PRE_APPROVAL_REQUIRED"` · severity = **MEDIUM**
- **권장 처리 · 확인/승인자:** 지정 승인자 승인 확인 전까지 보류, 미확인 시 보완요청 · 부서장(또는 지정대리인)
- **출처 조항:** *기업업무추진비 사용 규정 제6조①제2호*

#### R-103 · 사전승인 미확인 — 100만~300만원

- **조건(자연어):** 기업업무추진비 지출 금액이 100만원 초과 300만원 이하인데 부서장 이상의 사전승인 기록이 확인되지 않는 경우.
- **조건(룰 엔진 표현식):** `category == "기업업무추진비" AND 1000000 < amount <= 3000000 AND pre_approval_level < "부서장"`
- **액션 · 심각도:** `flag = "PRE_APPROVAL_REQUIRED"` · severity = **MEDIUM**
- **권장 처리 · 확인/승인자:** 지정 승인자 승인 확인 전까지 보류, 미확인 시 보완요청 · 부서장 이상
- **출처 조항:** *기업업무추진비 사용 규정 제6조①제3호*

#### R-104 · 사전승인 미확인 — 300만원 초과

- **조건(자연어):** 기업업무추진비 지출 금액이 300만원을 초과하는데 본부장 이상(본부장 직위가 없는 부서는 담당 임원 또는 대표이사)의 사전승인 기록이 확인되지 않는 경우.
- **조건(룰 엔진 표현식):** `category == "기업업무추진비" AND amount > 3000000 AND pre_approval_level < "본부장"`
- **액션 · 심각도:** `flag = "PRE_APPROVAL_REQUIRED"` · severity = **HIGH**
- **권장 처리 · 확인/승인자:** 고액 구간이므로 승인 미확인 시 반려 권고로 상향 처리 · 본부장 이상 / 대표이사
- **출처 조항:** *기업업무추진비 사용 규정 제6조①제4호*

#### R-105 · 행사성 접대 사전승인 누락

- **조건(자연어):** 골프 등 행사성 접대(제4조제4호)에 해당하는 지출인데, 지출 금액과 무관하게 부서장 이상의 사전승인 및 행사 목적·참석자 명단·예산 계획 첨부가 확인되지 않는 경우.
- **조건(룰 엔진 표현식):** `category == "기업업무추진비" AND entertainment_type == "행사성" AND (pre_approval_level < "부서장" OR event_plan_attached == false)`
- **액션 · 심각도:** `flag = "EVENT_ENTERTAINMENT_APPROVAL_REQUIRED"` · severity = **MEDIUM**
- **권장 처리 · 확인/승인자:** 승인·첨부서류 확인 전까지 보류 · 부서장 이상
- **출처 조항:** *기업업무추진비 사용 규정 제6조③*

#### R-106 · 청탁금지법 적용대상자 한도 초과

- **조건(자연어):** 피접대자 중 청탁금지법 적용대상자가 1인 이상 포함되고, 유형별 1인당 지급액이 별표1 한도(음식물 3만원 / 선물 5만원·농수산물 15만원 / 경조사비 5만원·화환 10만원)를 초과하는 경우.
- **조건(룰 엔진 표현식):** `has_kickback_law_target == true AND per_person_amount[gift_type] > kickback_limit_table[gift_type]`
- **액션 · 심각도:** `flag = "KICKBACK_LAW_LIMIT_EXCEEDED"` · severity = **HIGH**
- **권장 처리 · 확인/승인자:** 승인 보류 후 법무부서 사전 자문 필수 — 다른 룰 결과와 무관하게 최우선 적용 · 법무부서
- **출처 조항:** *기업업무추진비 사용 규정 제6조④, 제8조, 별표1*

#### R-107 · 사전승인 없이 지출·사후승인 미이행

- **조건(자연어):** 사전승인 대상 금액 구간의 지출인데 사전승인을 받지 못했고, 지출 후 1영업일 이내 사후승인 신청·소명도 이루어지지 않은 경우.
- **조건(룰 엔진 표현식):** `pre_approval_obtained == false AND amount > 300000 AND post_approval_within_1biz_day == false`
- **액션 · 심각도:** `flag = "APPROVAL_MISSING"` · severity = **HIGH**
- **권장 처리 · 확인/승인자:** 정산 거부 검토 — 지출 담당자 본인 부담 여부 확인 · 재무회계팀 / 관리자
- **출처 조항:** *기업업무추진비 사용 규정 제6조②⑤*

#### R-108 · 기록 사항 누락·불충분

- **조건(자연어):** 거래처명·피접대자 소속·참석자 명단 중 일부가 누락되었거나, 지출 목적이 "거래처 미팅" 등 포괄적으로만 기재되어 업무 관련성을 특정하기 어려운 경우.
- **조건(룰 엔진 표현식):** `category == "기업업무추진비" AND (vendor_info_missing OR participant_list_missing OR purpose_is_generic == true)`
- **액션 · 심각도:** `flag = "RECORD_INCOMPLETE"` · severity = **MEDIUM**
- **권장 처리 · 확인/승인자:** 보완요청 — 기한 내 미보완 시 반려 · 재무회계팀
- **출처 조항:** *기업업무추진비 사용 규정 제7조①③*

#### R-109 · 금지업종·현금성 사용

- **조건(자연어):** 유흥업소 또는 사행성 업종에서 결제하였거나, 상품권 등 유가증권을 현금으로 구매한 경우.
- **조건(룰 엔진 표현식):** `merchant_type IN ("유흥업소", "사행성업종") OR (item_type == "상품권" AND payment_method == "현금")`
- **액션 · 심각도:** `flag = "PROHIBITED_MERCHANT_OR_PAYMENT"` · severity = **CRITICAL**
- **권장 처리 · 확인/승인자:** 자동 반려 후보 — 시스템 최우선 경고, 관리자 최종 반려 확정 · 관리자(최종 확정)
- **출처 조항:** *기업업무추진비 사용 규정 제12조①③, 법인카드 사용 규정 제9조②③*

#### R-110 · 봉사료 과다 포함

- **조건(자연어):** 결제 금액 중 봉사료가 100분의 10 이상 포함된 경우, 업무 관련성을 특히 엄격히 심사한다.
- **조건(룰 엔진 표현식):** `category == "기업업무추진비" AND service_charge_ratio >= 0.10`
- **액션 · 심각도:** `flag = "HIGH_SERVICE_CHARGE"` · severity = **MEDIUM**
- **권장 처리 · 확인/승인자:** 소명자료 제출 요청 · 재무회계팀
- **출처 조항:** *기업업무추진비 사용 규정 제12조②*

#### R-111 · 경조사 화환·조의금 증빙 미비

- **조건(자연어):** 거래처 관계자 경조사에 대한 화환·조의금 등이 20만원을 초과하는데 청첩장·부고장·계좌이체 내역 등 소명자료가 없는 경우. 초과분이 아니라 지출 전액이 손금불산입된다.
- **조건(룰 엔진 표현식):** `category == "기업업무추진비" AND item_type == "경조사" AND amount > 200000 AND has_supporting_evidence == false`
- **액션 · 심각도:** `flag = "NON_DEDUCTIBLE_RISK"` · severity = **HIGH**
- **권장 처리 · 확인/승인자:** 반려 권고 — 전액 손금불산입 대상 · 재무회계팀
- **출처 조항:** *기업업무추진비 사용 규정 제11조②, 법인카드 사용 규정 제11조③*

#### R-112 · 반복·고액 접대 모니터링

- **조건(자연어):** 동일 거래처를 대상으로 최근 3개월 이내 3회 이상 반복 발생한 접대이거나, 1회 지출 금액이 100만원을 초과하는 접대 건인 경우.
- **조건(룰 엔진 표현식):** `same_vendor_count_3m >= 3 OR amount > 1000000`
- **액션 · 심각도:** `flag = "REPEAT_OR_HIGH_VALUE_REVIEW"` · severity = **MEDIUM**
- **권장 처리 · 확인/승인자:** 업무 관련성·적정성 별도 확인 — 개별 건 승인 여부와 별개로 재무회계팀 정기 점검에 반영 · 재무회계팀
- **출처 조항:** *기업업무추진비 사용 규정 제13조①②*

#### R-113 · 기록 기한 초과 (3영업일)

- **조건(자연어):** 지출일로부터 3영업일 이내에 기록해야 할 사항(거래처·참석자·목적 등)을 그 기한 내에 등록하지 않은 경우.
- **조건(룰 엔진 표현식):** `category == "기업업무추진비" AND business_days_since_expense > 3`
- **액션 · 심각도:** `flag = "LATE_RECORD"` · severity = **LOW**
- **권장 처리 · 확인/승인자:** 보완요청 — 지연 사유 기재 요청 · 재무회계팀
- **출처 조항:** *기업업무추진비 사용 규정 제7조①*

### 상세 명세

#### R-201 · 사전승인 기준 금액 초과 (30만원)

- **조건(자연어):** 회식비 건당 총액이 30만원을 초과하는데 사전승인 기록이 확인되지 않는 경우. 직책과 무관하게 30만원 기준이 우선 적용된다.
- **조건(룰 엔진 표현식):** `category == "회식" AND amount > 300000 AND pre_approval_obtained == false`
- **액션 · 심각도:** `flag = "PRE_APPROVAL_REQUIRED"` · severity = **MEDIUM**
- **권장 처리 · 확인/승인자:** 승인 확인 전까지 보류, 없으면 사후승인 절차 안내 · 회식 단위별 승인권자(팀장→부서장 / 부서장→본부장·CEO / 본부장→CEO)
- **출처 조항:** *회식 관련 법인카드 운영 규정 제7조, 제8조①, 별표1*

#### R-202 · 야간 사용 (22시 이후)

- **조건(자연어):** 회식비 결제 시각이 22시 이후인 경우.
- **조건(룰 엔진 표현식):** `category == "회식" AND payment_time >= "22:00"`
- **액션 · 심각도:** `flag = "NIGHT_USAGE_APPROVAL_REQUIRED"` · severity = **LOW**
- **권장 처리 · 확인/승인자:** 사전 또는 익일 사후승인 확인 · 회식 단위별 승인권자
- **출처 조항:** *회식 관련 법인카드 운영 규정 제8조②*

#### R-203 · 주말·공휴일 사용

- **조건(자연어):** 회식비 결제일이 토요일, 일요일 또는 공휴일인 경우.
- **조건(룰 엔진 표현식):** `category == "회식" AND (day_of_week IN ("SAT","SUN") OR is_holiday == true)`
- **액션 · 심각도:** `flag = "WEEKEND_HOLIDAY_APPROVAL_REQUIRED"` · severity = **LOW**
- **권장 처리 · 확인/승인자:** 사전 또는 익일 사후승인 확인 · 회식 단위별 승인권자
- **출처 조항:** *회식 관련 법인카드 운영 규정 제8조③*

#### R-204 · 외부인 참석 → 업무추진비 재분류

- **조건(자연어):** 회식에 거래처·협력사 등 외부인이 1인 이상 참석한 경우. 참석 목적·인원 비중과 무관하게 해당 건 전체를 기업업무추진비로 재분류한다.
- **조건(룰 엔진 표현식):** `category == "회식" AND external_participant_count >= 1`
- **액션 · 심각도:** `flag = "RECLASSIFY_TO_ENTERTAINMENT"` · severity = **MEDIUM**
- **권장 처리 · 확인/승인자:** 항목을 기업업무추진비로 재분류하고 R-101~R-113 룰셋을 재적용(거래처명·참석자·목적 기록 필수) · 재무회계팀
- **출처 조항:** *회식 관련 법인카드 운영 규정 제2조, 제6조②*

#### R-205 · 고급업종 사용

- **조건(자연어):** 호텔, 특급 레스토랑 등 고급 업종에서 회식비를 결제한 경우.
- **조건(룰 엔진 표현식):** `category == "회식" AND merchant_grade IN ("호텔", "특급레스토랑")`
- **액션 · 심각도:** `flag = "PREMIUM_VENUE_APPROVAL_REQUIRED"` · severity = **MEDIUM**
- **권장 처리 · 확인/승인자:** 승인 확인 전까지 보류 · 회식 단위별 승인권자
- **출처 조항:** *회식 관련 법인카드 운영 규정 제8조⑤*

#### R-206 · 1인당 고액 주류 포함 식대

- **조건(자연어):** 주류를 포함하여 1인당 식대가 8만원을 초과하는 경우.
- **조건(룰 엔진 표현식):** `category == "회식" AND includes_alcohol == true AND per_person_amount > 80000`
- **액션 · 심각도:** `flag = "HIGH_PER_PERSON_APPROVAL_REQUIRED"` · severity = **MEDIUM**
- **권장 처리 · 확인/승인자:** 승인 확인 전까지 보류 · 회식 단위별 승인권자
- **출처 조항:** *회식 관련 법인카드 운영 규정 제8조⑥*

#### R-207 · 최소 참석 인원 미달

- **조건(자연어):** 카드 사용자 본인을 포함한 참석 인원이 2인 이하인 경우. 개인 식사로 추정하여 리뷰 대상이 된다.
- **조건(룰 엔진 표현식):** `category == "회식" AND participant_count <= 2`
- **액션 · 심각도:** `flag = "PERSONAL_MEAL_SUSPECTED"` · severity = **MEDIUM**
- **권장 처리 · 확인/승인자:** 보완요청 — 회식 목적·참석자 소명 요청 · 재무회계팀
- **출처 조항:** *회식 관련 법인카드 운영 규정 제6조①*

#### R-208 · 2차 비용·유흥업소 결제

- **조건(자연어):** 동일 회식 건에서 식당 결제 후 노래방·단란주점 등 별도 업소에서 후속 결제가 발생하였거나, 유흥업소·사행성 업종에서 결제한 경우.
- **조건(룰 엔진 표현식):** `category == "회식" AND (merchant_type IN ("노래방", "단란주점", "유흥업소") OR is_secondary_venue == true)`
- **액션 · 심각도:** `flag = "PROHIBITED_SECONDARY_EXPENSE"` · severity = **CRITICAL**
- **권장 처리 · 확인/승인자:** 자동 반려 후보 — 원칙적으로 회식비로 불인정, 개인 사용으로 추정하여 별도 심사 · 관리자(최종 확정)
- **출처 조항:** *회식 관련 법인카드 운영 규정 제5조, 제9조 준용*

#### R-209 · 금지 품목 구매

- **조건(자연어):** 상품권 등 유가증권 또는 개인 선물을 회식비 명목으로 구매한 경우.
- **조건(룰 엔진 표현식):** `category == "회식" AND item_type IN ("상품권", "개인선물")`
- **액션 · 심각도:** `flag = "PROHIBITED_ITEM"` · severity = **HIGH**
- **권장 처리 · 확인/승인자:** 반려 권고 · 재무회계팀
- **출처 조항:** *회식 관련 법인카드 운영 규정 제5조*

#### R-210 · 가족·사적 모임 추정

- **조건(자연어):** 참석자 구성이 가족·지인 등으로만 이루어진 사적 모임으로 추정되는 경우. 원칙적으로 법인카드 회식비 대상에서 제외한다.
- **조건(룰 엔진 표현식):** `category == "회식" AND family_or_personal_gathering_suspected == true`
- **액션 · 심각도:** `flag = "PERSONAL_GATHERING_SUSPECTED"` · severity = **HIGH**
- **권장 처리 · 확인/승인자:** 반려 권고 — 경조사 성격이면 경조사비 규정으로 재분류 검토 · 재무회계팀
- **출처 조항:** *회식 관련 법인카드 운영 규정 제6조③*

#### R-211 · 퇴사 완료자 참석

- **조건(자연어):** 퇴사가 완료되어 재직 관계가 종료된 자가 참석하였는데 부서장 이상의 사전승인이 확인되지 않는 경우. 재직 중 송별회 참석은 정상 인정한다.
- **조건(룰 엔진 표현식):** `category == "회식" AND participant_includes_former_employee == true AND pre_approval_level < "부서장"`
- **액션 · 심각도:** `flag = "FORMER_EMPLOYEE_PARTICIPANT"` · severity = **MEDIUM**
- **권장 처리 · 확인/승인자:** 승인 확인 전까지 보류 · 부서장 이상
- **출처 조항:** *회식 관련 법인카드 운영 규정 제6조④*

#### R-212 · 출장 중 회식

- **조건(자연어):** 출장 기간 중 발생한 회식(출장지 현지 회식 포함)인 경우.
- **조건(룰 엔진 표현식):** `category == "회식" AND during_business_trip == true`
- **액션 · 심각도:** `flag = "TRIP_DINNER_APPROVAL_REQUIRED"` · severity = **LOW**
- **권장 처리 · 확인/승인자:** 승인 확인 전까지 보류 · 회식 단위별 승인권자
- **출처 조항:** *회식 관련 법인카드 운영 규정 제8조⑦*

#### R-213 · 전사 회식 (금액 무관 사전승인)

- **조건(자연어):** 전사 임직원을 대상으로 하는 회식인 경우. 금액과 무관하게 CEO 사전승인이 항상 필요하다.
- **조건(룰 엔진 표현식):** `category == "회식" AND scope == "전사"`
- **액션 · 심각도:** `flag = "COMPANY_WIDE_EVENT_APPROVAL_REQUIRED"` · severity = **MEDIUM**
- **권장 처리 · 확인/승인자:** CEO 승인 확인 전까지 보류(금액 무관) · CEO
- **출처 조항:** *회식 관련 법인카드 운영 규정 제4조, 제8조⑧*

#### R-214 · 필수 증빙 누락

- **조건(자연어):** 참석자 명단, 회식 목적, 회식 장소·일시 중 일부가 정산 시스템에 기록되지 않은 경우.
- **조건(룰 엔진 표현식):** `category == "회식" AND (participant_list_missing OR purpose_missing OR venue_datetime_missing)`
- **액션 · 심각도:** `flag = "RECORD_INCOMPLETE"` · severity = **MEDIUM**
- **권장 처리 · 확인/승인자:** 보완요청 · 재무회계팀
- **출처 조항:** *회식 관련 법인카드 운영 규정 제10조*

#### R-215 · 동일 건 분할 결제

- **조건(자연어):** 회식 1건이 식당 결제 후 별도 업소에서 추가로 결제되는 등 2개 이상 가맹점으로 나뉘어 결제된 경우. 후속 결제 건은 원칙적으로 개인 사용으로 추정한다.
- **조건(룰 엔진 표현식):** `category == "회식" AND same_event_multiple_merchants == true`
- **액션 · 심각도:** `flag = "SPLIT_PAYMENT_SUSPECTED"` · severity = **HIGH**
- **권장 처리 · 확인/승인자:** 반려 권고 — 후속 결제분 별도 심사 · 재무회계팀
- **출처 조항:** *회식 관련 법인카드 운영 규정 제5조 단서*

#### R-216 · 사후승인 반복 (고위험 사용자)

- **조건(자연어):** 동일 사용자의 사후승인이 최근 3개월 이내 3회 이상 발생한 경우. 개별 건 승인과 별개로 사용자 리스크 등급에 반영한다.
- **조건(룰 엔진 표현식):** `user_post_approval_count_3m >= 3`
- **액션 · 심각도:** `flag = "HIGH_RISK_USER"` · severity = **MEDIUM**
- **권장 처리 · 확인/승인자:** 관리자 재발 방지 조치 검토 대상으로 등록 · 관리자
- **출처 조항:** *회식 관련 법인카드 운영 규정 부칙, 법인카드 사용 규정 제13조①*

## 6. 출장 RULE (R-3xx)

「출장비 사용 규정」(TIGER-REG-2026-004)을 근거로 도출한 12개 RULE이다. 출장 중 발생한 회식은 R-212(회식 RULE) 및 본 문서의 R-303(야간식대)·R-310(접대성 식대)이 함께 검토 대상이 될 수 있다.

### 개요표

| ID | 제목 | 조건 요약 | 심각도 | 권장 처리 |
|---|---|---|---|---|
| R-301 | 해외출장 예산 100만원 초과 사전승인 누락 | 항공+숙박 합산 100만원 초과, 부서장 이상 승인 없음 | **MEDIUM** | 승인 확인 전까지 보류 |
| R-302 | 숙박비 상한 초과 | 1박 숙박비가 국내/해외 등급별 상한 초과 | **MEDIUM** | 초과분 본인 부담 여부 확인 또는 부서장 사전승인 확인 |
| R-303 | 야간식대 인정기준 미충족 | 야간식대로 청구했으나 근무종료시각(기본 18시) 이전 결제 | **LOW** | 일반 식비로 재분류하거나 소명 요청 |
| R-304 | 금지업종 사용 (유흥·사행성) | 유흥업소·카지노·경마 등 사행성 업종 결제 | **CRITICAL** | 자동 반려 후보 |
| R-305 | 업무관련성 낮은 업종 사용 | 이용업·미용업 등, 부서장 승인 없음 | **HIGH** | 반려 권고 |
| R-306 | 봉사료 과다 포함 | 결제금액 중 봉사료 10% 이상 포함 | **MEDIUM** | 소명자료 제출 요청 |
| R-307 | 정산기한 초과 (7영업일) | 출장 종료일로부터 7영업일 초과 | **LOW** | 보완요청 |
| R-308 | 사전예약-실사용 시차 확인서 미제출 | 예약~출장일 2개월 이상 & 확인서 미제출 | **MEDIUM** | 재무회계팀 재검토 |
| R-309 | 가맹점 정보 불명확 | 간편결제 등으로 원 가맹점 정보 확인 어려움 | **LOW** | 영수증 또는 이용내역 첨부 요청 |
| R-310 | 접대성 식대 겸유 기록 누락 | 출장 중 접대성 식대, 참석자 인원·소속 기록 없음 | **MEDIUM** | 보완요청 |
| R-311 | 항공권 등급 정책 위반 | 이코노미 원칙 위반 또는 프리미엄이코노미 요건 미충족 | **MEDIUM** | 반려 권고 또는 보완요청 |
| R-312 | 직책별 사전승인 기준금액 초과 | 건당 지출이 직책별 사전승인 기준(별표1) 초과, 승인 없음 | **MEDIUM** | 승인 확인 전까지 보류 |

### 상세 명세

#### R-301 · 해외출장 예산 100만원 초과 사전승인 누락

- **조건(자연어):** 해외출장의 항공권·숙박비를 합산한 총 예산이 100만원을 초과하는데 부서장 이상의 사전승인이 확인되지 않는 경우. 직책과 무관하게 적용한다.
- **조건(룰 엔진 표현식):** `category == "출장" AND trip_type == "해외" AND (flight_amount + lodging_amount) > 1000000 AND pre_approval_level < "부서장"`
- **액션 · 심각도:** `flag = "OVERSEAS_TRIP_PRE_APPROVAL_REQUIRED"` · severity = **MEDIUM**
- **권장 처리 · 확인/승인자:** 승인 확인 전까지 보류 · 부서장 이상
- **출처 조항:** *출장비 사용 규정 제5조②*

#### R-302 · 숙박비 상한 초과

- **조건(자연어):** 1박 숙박비가 국내출장 15만원, 해외출장 A등급 25만원 / B등급 18만원 / C등급 15만원 상한을 초과하는 경우.
- **조건(룰 엔진 표현식):** `lodging_amount_per_night > lodging_limit_table[trip_type][region_grade]`
- **액션 · 심각도:** `flag = "LODGING_LIMIT_EXCEEDED"` · severity = **MEDIUM**
- **권장 처리 · 확인/승인자:** 초과분 본인 부담 여부 확인 또는 부서장 사전승인 확인 · 부서장
- **출처 조항:** *출장비 사용 규정 제7조②, 별표1·별표2*

#### R-303 · 야간식대 인정기준 미충족

- **조건(자연어):** 야간식대로 청구되었으나 결제 시각이 통상 근무 종료 시각(기본 오후 6시, 개인 등록 근무스케줄 기준) 이전인 경우.
- **조건(룰 엔진 표현식):** `expense_type == "야간식대" AND payment_time < work_end_time`
- **액션 · 심각도:** `flag = "NIGHT_MEAL_NOT_QUALIFIED"` · severity = **LOW**
- **권장 처리 · 확인/승인자:** 일반 식비로 재분류하거나 소명 요청 · 재무회계팀
- **출처 조항:** *출장비 사용 규정 제10조*

#### R-304 · 금지업종 사용 (유흥·사행성)

- **조건(자연어):** 출장 중 유흥업소 또는 카지노·경마 등 사행성 업종에서 결제한 경우.
- **조건(룰 엔진 표현식):** `category == "출장" AND merchant_type IN ("유흥업소", "사행성업종", "카지노", "경마")`
- **액션 · 심각도:** `flag = "PROHIBITED_MERCHANT"` · severity = **CRITICAL**
- **권장 처리 · 확인/승인자:** 자동 반려 후보 — 관리자 최종 반려 확정 · 관리자(최종 확정)
- **출처 조항:** *출장비 사용 규정 제11조①, 법인카드 사용 규정 제9조②*

#### R-305 · 업무관련성 낮은 업종 사용

- **조건(자연어):** 이용업·미용업 등 출장 목적과 관련성이 인정되기 어려운 업종에서 결제하였는데 부서장 승인이 확인되지 않는 경우.
- **조건(룰 엔진 표현식):** `category == "출장" AND merchant_type IN ("이용업", "미용업") AND pre_approval_level < "부서장"`
- **액션 · 심각도:** `flag = "UNRELATED_MERCHANT"` · severity = **HIGH**
- **권장 처리 · 확인/승인자:** 반려 권고 — 부서장 사전승인 있는 예외적인 경우에 한해 인정 가능 · 부서장
- **출처 조항:** *출장비 사용 규정 제11조②*

#### R-306 · 봉사료 과다 포함

- **조건(자연어):** 결제 금액 중 봉사료가 100분의 10 이상 포함된 경우, 업무 관련성을 특히 엄격히 심사한다.
- **조건(룰 엔진 표현식):** `category == "출장" AND service_charge_ratio >= 0.10`
- **액션 · 심각도:** `flag = "HIGH_SERVICE_CHARGE"` · severity = **MEDIUM**
- **권장 처리 · 확인/승인자:** 소명자료 제출 요청 · 재무회계팀
- **출처 조항:** *출장비 사용 규정 제11조③*

#### R-307 · 정산기한 초과 (7영업일)

- **조건(자연어):** 출장 종료일로부터 7영업일 이내에 정산 시스템에 사용 내역·증빙·목적을 등록하지 않은 경우.
- **조건(룰 엔진 표현식):** `category == "출장" AND business_days_since_trip_end > 7`
- **액션 · 심각도:** `flag = "LATE_SETTLEMENT"` · severity = **LOW**
- **권장 처리 · 확인/승인자:** 보완요청 — 지연 사유 기재 요청 · 재무회계팀
- **출처 조항:** *출장비 사용 규정 제13조*

#### R-308 · 사전예약-실사용 시차 확인서 미제출

- **조건(자연어):** 항공권·숙박 조기 예약 등으로 예약 시점과 실제 출장일 사이에 2개월 이상 차이가 있는데, 출장 종료 후 7영업일 이내 확인서(목적·일정 일치 소명)가 제출되지 않았거나 예약 내역과 실제 출장 내역이 일치하지 않는 경우.
- **조건(룰 엔진 표현식):** `booking_to_trip_gap_months >= 2 AND (confirmation_doc_submitted == false OR itinerary_mismatch == true)`
- **액션 · 심각도:** `flag = "ADVANCE_BOOKING_CONFIRMATION_REQUIRED"` · severity = **MEDIUM**
- **권장 처리 · 확인/승인자:** 재무회계팀 재검토 — 보류 또는 반려 · 재무회계팀
- **출처 조항:** *출장비 사용 규정 제12조*

#### R-309 · 가맹점 정보 불명확

- **조건(자연어):** 간편결제(PG사 결제 등)로 인해 원 가맹점 정보 확인이 어려운 경우.
- **조건(룰 엔진 표현식):** `category == "출장" AND payment_method == "간편결제" AND merchant_info_resolved == false`
- **액션 · 심각도:** `flag = "MERCHANT_INFO_UNCLEAR"` · severity = **LOW**
- **권장 처리 · 확인/승인자:** 영수증 또는 이용내역 첨부 요청 · 재무회계팀
- **출처 조항:** *출장비 사용 규정 제9조③*

#### R-310 · 접대성 식대 겸유 기록 누락

- **조건(자연어):** 출장 중 기업업무추진비 성격을 겸하는 접대성 식대인데 참석자 인원 및 소속이 정산 시스템에 기록되지 않은 경우.
- **조건(룰 엔진 표현식):** `category == "출장" AND meal_type == "접대성" AND participant_record_missing == true`
- **액션 · 심각도:** `flag = "RECORD_INCOMPLETE"` · severity = **MEDIUM**
- **권장 처리 · 확인/승인자:** 보완요청 · 재무회계팀
- **출처 조항:** *출장비 사용 규정 제9조②*

#### R-311 · 항공권 등급 정책 위반

- **조건(자연어):** 해외출장 항공권이 이코노미·프리미엄이코노미가 아니거나, 프리미엄이코노미인데 비행시간 8시간 미만이거나 본부장 미만 직책자가 사용한 경우.
- **조건(룰 엔진 표현식):** `trip_type == "해외" AND (flight_class NOT IN ("이코노미","프리미엄이코노미") OR (flight_class == "프리미엄이코노미" AND (flight_duration_hours < 8 OR position < "본부장")))`
- **액션 · 심각도:** `flag = "FLIGHT_CLASS_POLICY_VIOLATION"` · severity = **MEDIUM**
- **권장 처리 · 확인/승인자:** 반려 권고 또는 보완요청 — 사유 소명 요청 · 부서장 이상
- **출처 조항:** *출장비 사용 규정 제8조②*

#### R-312 · 직책별 사전승인 기준금액 초과

- **조건(자연어):** 건당 출장비 지출이 「법인카드 사용 규정」 별표1의 직책별 사전승인 기준액(팀장 50만원 / 부서장 60만원 / 본부장 80만원 / 대표이사 100만원 / 비직책자 30만원)을 초과하는데 해당 승인이 확인되지 않는 경우.
- **조건(룰 엔진 표현식):** `amount > pre_approval_threshold_table[position] AND pre_approval_level < position_required_level`
- **액션 · 심각도:** `flag = "PRE_APPROVAL_REQUIRED"` · severity = **MEDIUM**
- **권장 처리 · 확인/승인자:** 승인 확인 전까지 보류 · 직책별 사전승인 기준의 승인권자
- **출처 조항:** *출장비 사용 규정 제5조①, 법인카드 사용 규정 별표1*

## 7. RULE 간 상호작용 및 우선순위

- **재분류 연쇄**: 회식에 외부인이 참석하면(R-204) 해당 건은 업무추진비로 재분류되어 R-101~R-113 RULE셋이 전체 재적용된다. 이때 원래 회식 RULE(R-201 사전승인·R-202 야간·R-203 주말 등)은 해제되고 업무추진비 RULE의 사전승인 구간(R-102~R-105)으로 대체된다.
- **최우선 적용 RULE**: 청탁금지법 한도 초과(R-106)는 접대 유형·금액과 무관하게 최우선으로 평가하며, 다른 RULE이 승인 방향으로 판정되어도 R-106이 트리거되면 반드시 법무부서 에스컬레이션을 거친다.
- **CRITICAL 심각도 RULE**(R-109, R-208, R-304)은 다른 RULE 평가 결과와 무관하게 최우선으로 표시되며, 검토 워크스페이스 목록 최상단에 노출한다.
- **배타적 구간 RULE**: 사전승인 금액구간 RULE(R-102~R-105, R-201, R-301, R-312)은 조건이 금액 구간으로 서로 배타적이므로 한 건당 하나만 매칭되어야 한다. 신규 RULE 등록 시 콘솔의 조건 겹침 검사로 상호 배타성을 검증한다.
- **모니터링성 RULE**: 반복·지연 계열 RULE(R-112, R-113, R-216, R-307)은 개별 건의 승인/보완요청/반려 판정에 직접 영향을 주지 않고, 사용자 리스크 등급 및 정기 점검 리포트에 누적 반영하는 용도로 운영한다.

## 8. 운영 프로세스 및 유지관리

- **규정 개정 연동**: 각 RULE은 출처 조항을 태깅하므로, 해당 조항이 개정되면(예: 법인카드 사용 규정 제18조, 기업업무추진비 사용 규정 제16조, 회식 규정 부칙, 출장비 규정 제15조에 따른 개정) 관련 RULE을 재검토 대상으로 자동 플래그하고 재시뮬레이션 후 재승인 절차를 거친다.
- **버전 관리**: RULE 개정 시 기존 Active 버전은 과거 버전으로 보존되며, 매칭 건수·오탐율 변화를 기준으로 필요 시 이전 버전으로 롤백할 수 있다.
- **승인 권한**: RULE의 Active 전환은 팀장급 이상만 수행할 수 있으며, 재무회계 담당자 단독으로는 전환할 수 없다.
- **재무회계부 자체 건의 이해상충 방지**: 재무회계부가 지출 주체인 건은 감사실이 사후 검증을 수행한다(회식 규정 제9조③ 준용, 전 카테고리 공통 적용 권장).
