# 📋 일간 보고 (07/27)

## 1. 데이터 전처리 및 머신러닝

* 머신러닝 학습에 사용할 Feature를 최종 검토하고, 실제 서비스에서도 수집·활용 가능한 Feature만 선별하여 확정하였다.
* 모델 학습을 위한 데이터 전처리 및 Feature 구성을 완료하고, 데이터셋을 정비하였다.
* 기존 랜덤 Train/Test Split 방식에서 시계열 Feature 사용 시 발생할 수 있는 데이터 누수(Data Leakage)를 방지하기 위해 데이터 분할 방식을 재검토하였다.
* 카드별 분할과 시간 기준 분할을 비교한 결과, 실제 운영 환경과 가장 유사한 **시간 기준 분할(Time-based Split)** 을 적용하기로 결정하였다.
* 현재 **XGBoost, LightGBM, Random Forest**를 주요 지도학습 모델로 학습 중이며, **Isolation Forest**를 활용한 비지도 이상거래 탐지도 함께 비교·검증하고 있다.
