# 📋 일간 보고 (08/24)

## 1. 산출물 현행화 작업 진행

* **타이거 규정 세트 정비** — `TIGER-REG` 문서번호 체계를 md·코드 전반에서 제거하고, 법인카드 제8조·제15조를 실제 규정명으로 참조하도록 갱신
* **식대 사용 규정·회의비 사용 규정 신설** — 식대는 자동 처리 기준(금액·인원·시점)과 시간대별 한도(별표1)를 정의, 회의비는 사전 일정 등록을 성립 요건으로 하는 분류 체계를 정의
* 법인카드 제15조를 기업업무추진비·출장비·회의비·회식비·식대 5개 지출 유형 순으로 재편, 실사용 중이 아니던 광고선전비 항목 삭제
* 회식·업무추진비·출장비 규정 간 인용·표기를 통일하고, 규정 문서에 남아 있던 내부 시스템 구현 용어(룰 엔진 등)를 제거
* 전 규정 PDF를 하우스 스타일(표지·헤더/푸터·표 레이아웃)로 재생성, `회식_운영규정.pdf` → `회식_사용규정.pdf`로 파일명 명명 규칙 통일
* **PDF 페이지 나눔 개선** — 표가 제목만 남기고 통째로 다음 페이지로 밀리던 문제를 행(tr) 단위 분리로 해결, 별표 제목 단독 페이지 방지, 회식 규정 별표1 열 너비 조정으로 줄바꿈 완화
* **기본 회사 도메인 시드 & 벡터DB 덤프 기능 추가** — 재임베딩 없이 시연용 벡터 상태를 고정·복원할 수 있는 경로 확보
* `seed_adopted`(3개월 운영 이력) 시드 데이터 전면 개편 진행 — 관련 회귀 테스트 함께 정비

## 2. QA 검수

* **QA 라이브 테스트(50건×4 에이전트)** 로 결함을 찾아 그중 2건을 수정·재검증
  * RAG 스코프 누수 — 카테고리 구분 없이 `policy_docs` 전체를 검색해 회식 규정이 식대·회의 질의에 새어 들어오던 문제를 확인, scope→허용 문서명 조회 API(`PolicyDocScopeMapView`) 신설로 Rule Agent·Risk Review Agent 양쪽에 연결. 재검증 케이스에서 더 이상 무관 규정을 인용하지 않음을 확인
  * 증빙 추출 값 날조 방어 — 근거(quote)는 불확실성을 표시하는데 확정값을 내는 자기모순을 잡는 `is_uncertain()` 유틸 추가, 숫자 경로 타입 체크·전결/부분승인 프롬프트 보강
* QA 도구가 Chroma에 남긴 고아 데이터(PolicyDoc 미기재)를 정식 업로드 경로로 재적재해 정합화
* E2E 테스트가 매 실행마다 남기는 "규정 문서 처리 실패" 알림이 화면에 계속 쌓이던 문제를 제목 기준으로 걸러 임시 차단(행 자체는 남아 있어 근본 조치는 후속 과제로 기록)
* 시드 데이터 진입 시 화면이 죽지 않도록 `ScreenErrorBoundary` 등 렌더링 방어 로직 추가
* 자기등록(실사용자 미매칭) 사용자 케이스의 인식 facts 어긋남을 확인해 조정, 백필 마이그레이션과 테스트 추가
