# 📋 일간 보고 (08/10)

## 1. Draft Agent 생성 및 구현

* RAG 파이프라인에서 문서 검색 및 답변 생성을 담당할 **Draft Agent의 역할과 처리 흐름을 구체화**하였다.
* Draft Agent의 기본 구조를 생성하고, 이후 검색된 문서와 규정 내용을 기반으로 답변 초안을 생성할 수 있도록 **Agent 구현을 진행**하였다.
* 향후 검색 결과와 연계하여 **근거 기반의 답변 생성 및 후처리 로직**을 확장할 수 있도록 기반을 마련하였다.

## 2. 규정 문서 파싱·청킹 및 임베딩

* 규정 문서를 대상으로 **문서 파싱 및 텍스트 추출 작업**을 진행하였다.
* 문서의 구조와 의미 단위를 고려하여 검색에 적합한 형태로 **청킹 전략을 적용**하였다.
* 생성된 Chunk를 기반으로 **Embedding 작업을 수행하여 벡터 검색에 활용할 수 있는 데이터 형태로 구성**하였다.

## 3. 파싱·청킹 품질 평가

* 규정 문서 파싱 결과와 청킹 결과를 직접 검토하여 **문서 구조가 적절하게 보존되는지 평가**하였다.
* Chunk 단위가 지나치게 크거나 작아지는 문제, 문맥이 중간에 단절되는 문제 등을 중심으로 **청킹 품질을 점검**하였다.
* 평가 결과를 바탕으로 향후 **파싱 및 청킹 전략을 보완하고 RAG 검색 성능을 개선할 수 있는 기반을 마련**하였다.

### ✅ 진행 결과

* **Draft Agent 기본 구현 진행**
* **규정 문서 파싱 → 청킹 → 임베딩 파이프라인 구축**
* **파싱 및 청킹 결과에 대한 1차 품질 평가 진행**
* 평가 결과를 기반으로 **RAG 검색 품질 개선 방향 도출**
