# archive/early_eda_preprocessing/ — 초기 EDA·전처리 (참고용, 최신 아님)

법인카드 이상거래 데이터를 처음 살펴보고 전처리 방식을 잡아가던 초기 단계 노트북들.
이후 발견된 개선사항(가맹점 피처 제외, 시간 기준 분할 등)은 [`../../mvp_isolation_forest/`](../../mvp_isolation_forest/)의
`v2`/`v3` 노트북에 반영되어 있으므로, **최신 기준은 이 폴더가 아니라 `mvp_isolation_forest/`다.**

| 파일 | 역할 |
|---|---|
| `법인카드_이상거래_EDA.ipynb` | 최초 탐색적 데이터 분석(EDA) |
| `법인카드_이상거래_EDA_v2.ipynb` | EDA 2차 — 추가 탐색 |
| `법인카드_이상거래_EDA_v3.ipynb` | EDA 3차 — 추가 탐색 |
| `법인카드_이상거래_전처리.ipynb` | 초기 전처리 노트북(가맹점 피처 제외·시간 기준 분할 반영 전 버전) |
| `전처리_노트북_리뷰_통합본.md` | 위 전처리 노트북에 대한 리뷰 정리 |
